## 📱 Overview

Expenso is a modern, feature-rich expense tracking application built with Flutter. It helps users manage their finances effectively with a beautiful and intuitive user interface, supporting both light and dark themes.

## ✨ Features

- 💰 Track daily expenses and income
- 🌓 Beautiful Material Design 3 UI with light/dark theme support
- 🔐 Secure authentication system
- 📊 Visual expense analytics and reports
- 💳 Multiple expense categories
- 🔄 Real-time data synchronization
- 📱  Support Android

## 🎨 UI/UX Highlights

- Modern Material Design 3 implementation
- Custom color scheme with primary color `#6C63FF`
- Responsive and adaptive layouts
- Smooth animations and transitions
- Intuitive navigation
- Elegant typography using Google Fonts (Poppins)

## 🛠️ Technical Stack

- **Framework**: Flutter
- **State Management**: Provider
- **Fonts**: Google Fonts
- **Architecture**: Provider Pattern
- **Theme**: Material Design 3

## 🚀 Getting Started

### Prerequisites

- Flutter SDK (latest version)
- Dart SDK (latest version)
- Android Studio / VS Code
- Git

### Installation

1. Clone the repository
```bash
git clone https://github.com/yourusername/expenso.git
```

2. Navigate to project directory
```bash
cd expenso
```

3. Install dependencies
```bash
flutter pub get
```

4. Run the app
```bash
flutter run
```
